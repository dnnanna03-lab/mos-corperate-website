# Mega Ortho Services Nigeria Limited (MOS) Website — Starter 1.0

A responsive Next.js App Router website starter for MOS using React, TypeScript, Tailwind CSS, and Lucide icons. Brand styling uses navy blue, metallic gold, and white, with a logo placeholder that must be replaced by the supplied official MOS artwork (the placeholder itself does not redraw the logo).

## Pages included
- `/` Home
- `/about` About MOS
- `/products` Products & Supplies
- `/services` Services
- `/request-a-quote` Request a Quote
- `/contact` Contact


## Local development
1. Install Node.js 20 or newer.
2. From this folder, run `npm install`.
3. Run `npm run dev` and open `http://localhost:3000`.
4. To build for production, run `npm run build`, then `npm run start`.


## Important before launch
- Enquiry forms currently validate client-side and show a demo confirmation. They do **not** send data anywhere yet. Connect a server action/API route and a mail service (or CRM) before publishing.
- Confirm MOS phone/WhatsApp, business address, company profile wording, and email inbox.
- Replace the `LogoPlaceholder` component with the approved original MOS logo file without modifying the artwork.
- Confirm hosting, DNS and domain registration for `megaorthoservices.ng`.
- Add real product catalogue content, images, prices if applicable, and inventory rules.
- Perform accessibility, responsive, browser, SEO and security checks before deployment.
- MOS website deployment verification update.
